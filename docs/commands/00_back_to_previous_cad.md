---
title: Back to previous CAD
---

Restores the CAD state to the step just before the most recent action.

### Keyboard shortcut

- `Ctrl+Z`

### What it does

The **Back to previous CAD** command replays the recorded script up to the previous action.
In practice, this undoes the latest CAD operation.

### Inputs

- **None**: this command operates on the active replay history.

### Output

- The CAD model is restored to its previous state.

### Basic usage

Click **Back to previous CAD** to move back one CAD step.

### Notes

1. The current script is re-executed up to the previous command.
2. The most recent CAD action is removed from the active state.
3. Continue editing from that restored point.
